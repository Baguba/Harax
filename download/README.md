# Harax downloads

- **harax.zip** — the complete Harax platform source, ready to run.

## How to run it

1. Unzip the file.
2. Requirements: Node.js 20+ (with npm).
3. In the unzipped `harax/` folder:

```bash
npm install
npm run dev
```

4. Open http://localhost:3000

New in this build: **Game Zone** — play X & O, checkers and chess against anyone on campus in realtime, stack weekly points, climb the leaderboard and the top 3 every Monday take trophies + campus vouchers. Also includes profile photo/banner uploads and the profile Log out button.
