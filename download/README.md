# Harax downloads

- **harax.zip** — the complete Harax platform source, ready to run.

## How to run it

1. Unzip the file.
2. Requirements: Node.js 20+ (with npm).
3. In the unzipped `harax/` folder:

```bash
npm install
npm run dev
```

4. Open http://localhost:3000

New in this build: tap the camera badge on your avatar or "Add banner photo" on your profile to upload your own profile photo and banner (JPG/PNG/WebP/GIF, cleaned up automatically when replaced).
